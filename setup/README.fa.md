# نصب ویندوز

روش تک‌دستوری از [README](../README.md#نصب-با-یک-دستور-در-ویندوز) قابل اجراست؛ به نصب قبلی Node یا Git نیاز ندارد و ابزارها را از منابع رسمی با بررسی SHA256 دریافت می‌کند. اجرای دوباره تنظیمات نصب قبلی را حفظ می‌کند و اتصال را بررسی می‌کند. این روش نیازمند انتشار `install.ps1` و فایل‌های `setup` در مخزن است.

فایل Setup.exe را روی ویندوز ۶۴ بیتی اجرا کنید. Node و Codex همراه بسته هستند؛ نصب برای کاربر فعلی و بدون نیاز به دسترسی مدیر انجام می‌شود. برای ورود اولیه به حساب خودتان به اینترنت نیاز دارید.

مسیر نصب: `%LOCALAPPDATA%\CodexLocalGateway`

بعد از ورود به Codex، سرویس اجرا و داشبورد باز می‌شود. میان‌برهای اجرا، ورود، داشبورد و حذف در منوی Start قرار می‌گیرند. سرویس در ورود بعدی به ویندوز نیز اجرا می‌شود.

توکن تازه در `.env.local` مسیر نصب ذخیره می‌شود. آن را فقط به برنامهٔ محلی مورد اعتماد بدهید. بسته شامل حساب، تنظیمات یا توکن سازنده نیست. دسترسی نوشتن غیرفعال است و مسیر مجاز در ابتدا فقط پوشه نصب است؛ برای استفاده از پروژه خود، CODEX_ALLOWED_ROOTS را در همین فایل تنظیم و سرویس را دوباره اجرا کنید.

حذف از تنظیمات برنامه‌های ویندوز یا میان‌بر Uninstall انجام می‌شود. تنظیمات و گزارش‌ها باقی می‌مانند؛ حساب Codex نیز خارج نمی‌شود.

این بسته امضای دیجیتال ندارد و ویندوز ممکن است درباره ناشر ناشناس پیام نشان دهد. نصب روی سیستم مستقل هنوز آزمایش نشده است.

برای بازسازی، build.ps1 را با PowerShell اجرا کنید. فقط فایل‌های فهرست‌شده برنامه و ابزارهای اجرایی بسته‌بندی می‌شوند؛ .env.local و اطلاعات ورود کپی نمی‌شوند. بررسی بدون نصب: `Setup.exe --verify`.
